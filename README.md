# Matrix Blocks
This mod adds blocks with green 1s and 0s to your game :3. \
This can be useful to decorate your creations (if you like computers) and I plan to add functional computers and smartphones sometime in the near future.

# What it adds
Blocks, stairs, slabs, buttons, pressure plates and more! Try it out!

# Requirements
- Minecraft
  - 1.20.4
  - 1.20.5
  - 1.20.6
- Fabric API
- Fabric Loader
